# prokursy-redesign-v1

Главная учебного центра «БиGOODи» (Vite + React + TypeScript + Tailwind).

Сборка рассчитана на Node 22. В репозитории можно использовать локальный бинарь `.tools/node` (не коммитится):

```
export PATH="$PWD/.tools/node/bin:$PATH"
npm install
npm run build   # base: ./
```

Демо: https://bonnatig-dev.github.io/prokursy-redesign-v1/
